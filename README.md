# 墨屿 · AI 写作工作台

一个无需安装、双击即可体验的私人写作平台原型。打开 `index.html` 即可使用。

## 已实现

- 沉浸式章节编辑器，字数统计、本地自动保存状态、新建项目
- AI 写作伙伴：连续对话界面、续写 / 润色 / 扩写 / 总结快捷操作
- 图片、视频、任意文件的附件选择与移除
- Gemini、DeepSeek、通义千问和自定义模型切换入口
- 自然叙事、J·K·罗琳、鲁迅、莫言等文风切换
- 联网检索开关（前端入口，可接入搜索 API）
- 自定义 API Base URL、API Key、模型名称设置弹窗
- 响应式布局：桌面三栏，窄屏自动切换为编辑器 + 对话流

## 接入真实模型

页面现在支持在浏览器中直接调用 OpenAI-compatible 接口；点击左下角齿轮，填写 Base URL、API Key 和模型名称后保存即可。若服务商限制浏览器跨域，建议增加一个轻量后端代理：

1. 后端读取设置弹窗中的 Base URL / Key，转发到 OpenAI-compatible `/chat/completions`。
2. 将 `send()` 中的请求地址改为 `fetch('/api/chat', { method: 'POST', body: ... })`。
3. 图片使用 `data_url`，视频和文件先在后端抽取文字 / 关键帧，再连同上下文发送。
4. 联网开关可接 Tavily、Serper 或自建搜索服务，将结果和来源注入 system prompt。

API Key 只应保存在后端或浏览器本地存储，不要提交到仓库。
